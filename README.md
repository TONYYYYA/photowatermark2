# 图片水印工具使用文档

## 概述
图片水印工具是一款功能完善的本地应用，支持在图片上添加文本或图片水印，适用于 Windows 和 MacOS 系统。该工具提供批量处理能力、丰富的样式设置和模板管理功能，帮助用户高效地为图片添加水印保护。

## 功能亮点
- 多方式导入图片（单张、批量、文件夹、拖拽）
- 支持文本水印和图片水印两种模式
- 实时预览水印效果，所见即所得
- 灵活的水印位置调整（预设位置 + 拖拽）
- 丰富的样式设置（透明度、旋转、字体等）
- 水印模板保存与加载，提升重复工作效率
- 多种导出选项（格式、命名规则、缩放等）

## 安装指南

### 系统要求
- 操作系统：Windows 7 及以上 / macOS 10.12 及以上
- 运行环境：Python 3.6 或更高版本

### 安装步骤
- **验证 Python 环境**：确保已安装 Python 环境，打开终端（Windows 用命令提示符，Mac 用终端应用），输入以下命令验证：
   ```bash
   python --version  # 或 python3 --version
- 若显示 Python 版本号（如 Python 3.8.10），则环境正常。
- 安装依赖库：在终端中执行以下命令，安装工具所需的 PyQt5（界面库）和 Pillow（图片处理库）：
  ```bash
    pip install pyqt5 pillow  # 或 pip3 install pyqt5 pillow
- 准备程序代码：下载图片水印工具的程序代码，将其保存为 watermark_tool.py 文件（确保文件路径无特殊字符，如中文空格、特殊符号）。
运行程序：在终端中进入 watermark_tool.py 所在的文件夹（通过 cd 文件夹路径 命令切换，例：cd C:\Users\XXX\Desktop），然后执行以下命令启动程序：
    ```bash
    python watermark_tool.py  # 或 python3 watermark_tool.py
- 启动成功后，将自动弹出工具的主操作窗口。
- 界面导航
程序界面分为三个主要部分，布局清晰，操作逻辑直观：
- 左侧：图片管理区
核心功能：展示已导入图片的缩略图和文件名，方便快速识别；
操作按钮：
“导入单张图片”：单次导入 1 张目标图片；
“导入多张 / 文件夹”：批量导入多张图片或整个文件夹内的所有图片；
“导出所有图片”：对已导入的所有图片批量添加水印并导出。
- 中间：预览区
核心功能：实时显示当前选中图片的水印效果，所见即所得；
交互操作：支持鼠标拖拽调整水印位置（点击水印后按住左键拖动，松开即可固定）；
切换方式：点击左侧图片列表中的任意图片，预览区将同步切换显示该图片的水印效果。
- 右侧：设置面板（标签页）
设置面板以标签页形式分类，共 4 个核心标签：
水印类型：配置文本水印或图片水印的详细参数（如文本内容、字体、图片路径、水印大小等）；
水印布局：调整水印的位置（九宫格预设位置）和旋转角度（0-360° 自定义）；
导出设置：配置输出目录、导出格式、文件命名规则，以及可选的 JPEG 质量、图片缩放参数；
模板管理：保存当前水印配置为模板、加载已保存的模板、删除不需要的模板。
- 操作教程
- 1. 导入图片
工具提供四种导入图片的方式，可根据需求选择：
单张导入：点击左侧 “导入单张图片” 按钮 → 在弹出的文件选择窗口中选中 1 张图片（支持格式见 “格式支持” 章节）→ 点击 “打开” 完成导入；
批量导入：点击左侧 “导入多张 / 文件夹” 按钮 → 在弹出的对话框中选择 “导入多张图片”→ 按住 Ctrl 键（Windows）/ Command 键（Mac）多选图片 → 点击 “打开” 完成导入；
文件夹导入：点击左侧 “导入多张 / 文件夹” 按钮 → 在弹出的对话框中选择 “导入整个文件夹”→ 选中存放图片的文件夹 → 点击 “选择文件夹”，工具将自动加载文件夹内所有支持格式的图片；
拖拽导入：直接从电脑文件夹中选中图片（或文件夹）→ 按住鼠标左键拖拽到左侧图片管理区 → 松开鼠标即可完成导入（支持跨窗口拖拽）。
- 2. 配置水印
根据需求选择 “文本水印” 或 “图片水印” 模式，进行参数配置：
-     文本水印设置
      切换到右侧 “水印类型” 标签页 → 确保下拉框选中 “文本水印”； 
      在 “文本内容” 输入框中填写水印文字（如 “© 2025 版权所有”）； 
      调整基础样式：
      字体：从下拉框选择系统已安装的字体（如 Windows 中的 “微软雅黑”、Mac 中的 “PingFang SC”）；
      字号：通过数字框设置（范围通常为 8-200，建议根据图片尺寸选择 24-48）；
      字体效果：勾选 “粗体” 或 “斜体”（可组合勾选，增强文字辨识度）；
      选择颜色：点击 “颜色” 按钮（彩色方块）→ 在调色板中选择文字颜色（支持自定义 RGB 数值）；
      调整透明度：拖动 “透明度” 滑块（0% 完全透明，100% 完全不透明，建议 30%-70%，平衡保护与美观）；
## 增强效果（可选）：
- 勾选 “添加阴影”：为文字添加浅灰色阴影，避免文字与复杂背景融合；
- 勾选 “添加描边”：为文字添加轮廓，提升文字在高清图片中的清晰度。
- 2.2 图片水印设置
- 切换到右侧 “水印类型” 标签页 → 下拉框选择 “图片水印”；
- 点击 “选择图片” 按钮 → 在文件选择窗口中选中作为水印的图片（推荐 PNG 格式，支持透明通道，避免水印边缘出现白色背景）；
- 调整水印大小：拖动 “水印大小” 滑块（范围 10%-200%，建议 20%-50%，确保不遮挡图片主体内容）；
- 调整透明度：拖动 “透明度” 滑块（建议 40%-80%，Logo 类水印可适当提高透明度，避免过于突兀）。
- 3. 调整水印布局
- 通过预设位置或手动拖拽，灵活调整水印在图片中的位置：
- 快速定位：切换到右侧 “水印布局” 标签页 → 点击九宫格按钮（如 “左上”“居中”“右下” 等），水印将一键定位到对应位置（默认保留 5% 边距，避免贴边）；
- 自由调整：在中间预览区点击水印 → 按住鼠标左键拖动水印到目标位置 → 松开鼠标即可固定；
- 旋转设置：在 “水印布局” 标签页的 “旋转角度” 输入框中填写数值（0-360°，如 45° 斜向水印、90° 垂直水印），或通过输入框右侧的上下箭头微调（每次 ±1°）。
- 4. 导出图片
- 完成水印配置和布局调整后，按照以下步骤导出图片：
- 切换到右侧 “导出设置” 标签页 → 点击 “选择文件夹” 按钮 → 选中输出目录（⚠️ 重要：禁止选择原图片所在文件夹，工具会自动检测并阻止，防止覆盖原图导致数据丢失）；
- 选择输出格式：
- “与原图一致”：保留导入图片的格式（如原图是 PNG 则导出为 PNG，原图是 JPG 则导出为 JPG）；
- “JPEG”：适合照片类图片（压缩体积小，加载快，但不支持透明通道）；
- “PNG”：适合需要透明背景的图片（质量高，支持透明通道，但体积较大）；
- 选择文件命名规则：
- “保留原文件名”：导出文件与导入文件同名（若输出目录已有同名文件，会自动覆盖，需谨慎）；
- “添加自定义前缀”：在输入框中填写前缀（如 “wm_”“版权_”），导出文件名格式为 “前缀 + 原文件名。格式”；
- “添加自定义后缀”：在输入框中填写后缀（如 “_watermarked”“_版权”），导出文件名格式为 “原文件名 + 后缀。格式”；
## 高级设置（可选）：
- JPEG 质量：仅当输出格式选择 “JPEG” 时显示，拖动滑块调整（0%-100%，建议 80%-90%，平衡质量与体积）；
图片缩放：从下拉框选择缩放模式（“不缩放”“按宽度缩放”“按高度缩放”“按百分比缩放”），并填写对应数值（如 “按宽度缩放”→ 输入 “1920”，即输出图片宽度固定为 1920 像素）；
点击左侧 “导出所有图片” 按钮 → 工具开始批量处理，处理完成后将弹出 “导出结果” 对话框，显示成功导出数量、失败数量及失败文件列表（若有）→ 点击 “确定” 完成导出。
- 5. 模板管理
- 当需要对多批图片使用相同的水印设置时，可通过模板功能提高效率：
- 保存模板：配置完水印参数（类型、样式、布局、导出设置）后 → 切换到右侧 “模板管理” 标签页 → 点击 “保存当前配置为模板”→ 在弹出窗口中输入模板名称（如 “公司 Logo 水印（右下）”“版权文本（居中 40% 透明）”）→ 点击 “确定”，模板将自动保存到系统目录；
- 加载模板：在 “模板管理” 标签页的模板列表中选中需要的模板 → 点击 “加载选中模板”→ 工具将自动同步所有水印设置（文本内容、字体、位置、透明度等），预览区实时更新效果；
- 删除模板：在 “模板管理” 标签页的模板列表中选中需要删除的模板 → 点击 “删除选中模板”→ 在确认对话框中选择 “是”→ 模板将被永久删除（不可恢复，需谨慎操作）。
- ℹ️ 提示：工具会自动保存上次关闭时的水印配置（保存为 last_config.json 文件），下次启动时将自动加载，无需手动保存为模板。
- 格式支持
- 输入格式：JPEG (.jpg, .jpeg)、PNG (.png)、BMP (.bmp)、TIFF (.tiff, .tif)
- 输出格式：JPEG (.jpg)、PNG (.png)、“与原图一致”（自动匹配输入格式）
## 常见问题
- Q: 导入图片时提示失败？
- A: 可能原因及解决方法：
- 图片文件已损坏：用系统自带图片查看器打开验证，若无法打开则需更换正常图片；
- 图片格式不受支持：确认图片格式在 “输入格式” 列表中（如 WebP 格式暂不支持，需先转换为 PNG/JPG）；
- 没有文件读取权限：将图片移动到桌面或非系统盘（如 D 盘），重新导入；
- 图片路径包含特殊字符：修改图片文件名或文件夹路径，去除中文空格、特殊符号（如 * ? |）。
- Q: 水印文字显示为乱码或方块？
- A: 通常是所选字体不支持当前输入的字符（如英文字体不支持中文），建议：
- 切换到 “水印类型” 标签页 → 在 “字体” 下拉框中选择系统默认字体（如 Windows 中的 “微软雅黑”“宋体”，Mac 中的 “PingFang SC”“Songti SC”）；
- 若字体选择正确仍显示异常，检查字体文件是否完整（系统字体目录：Windows 为 C:\Windows\Fonts，Mac 为 /Library/Fonts）。
- Q: 导出后水印位置与预览不一致？
- A: 可能是开启了 “图片缩放” 功能导致比例变化，建议：
- 导出前在 “导出设置”→“图片缩放” 中选择 “不缩放”；
- 若需要缩放，优先使用 “按百分比缩放”（如 100% 即不缩放），或调整水印位置时使用 “九宫格预设位置”，避免手动拖拽。
- Q: 如何批量处理大量图片？
- A: 推荐通过 “文件夹导入” 功能高效处理：
- 将所有需要处理的图片放入同一个文件夹（确保无损坏文件）；
- 在工具中点击 “导入多张 / 文件夹”→ 选择 “导入整个文件夹”→ 加载所有图片；
- 配置好水印参数和导出设置后，点击 “导出所有图片”，工具将一次性处理全部图片。
